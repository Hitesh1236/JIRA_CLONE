# Jira Clone Client

A React + Vite frontend for the Jira Clone project.

## Features
- User login and registration
- Project dashboard
- Project creation
- Project detail view
- Protected routes for authenticated users

## Scripts
- `npm install` — install dependencies
- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build locally

## Environment
Create a `.env` file in the project root and set:

```env
VITE_API_URL=http://localhost:3200/api/
```

## Notes
- Make sure your backend is running before using the app.
- The `dist` folder is generated by the build and is ignored by Git.
